# Search Engine UI (React Version)

![Search Engine UI Cover](/public/Assets/Image/Cover.jpg)

**Search Engine UI** is a modern, responsive web homepage that combines a search bar, live weather, a digital clock, motivational quotes, and a full-featured bookmark manager. Originally built with vanilla technologies, this version has been completely refactored using **React (Vite)** and **Tailwind CSS** for a more powerful, component-based architecture.

## ✨ Features

- **Live Weather**: Automatically detects your location to display the real-time temperature and city name.
- **Digital Clock**: Shows the current time, updating every second.
- **Random Quotes**: Displays a new, inspiring quote on each page load from a curated local list.
- **Smart Search Bar**: Type a search query to use Google, or enter a URL to navigate directly.
- **Advanced Bookmark Manager**:
  - Add your favorite websites with a clean modal interface.
  - View all bookmarks with their corresponding favicons.
  - **Edit and Delete** existing bookmarks with an intuitive on-hover menu.
  - All bookmarks are saved securely in your browser's local storage.
- **Component-Based Architecture**: Built with React for a maintainable and scalable codebase.
- **Responsive Design**: A fluid layout that looks great on both desktop and mobile devices.

## ⚡ Installation & Usage

To run this project locally, follow these steps:

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/saad-shaikh-256/Search-Engine-Ui.git
    ```

2.  **Navigate to the project folder:**

    ```bash
    cd Search-Engine-Ui
    ```

3.  **Install dependencies:**

    ```bash
    npm install
    ```

4.  **Start the development server:**
    ```bash
    npm run dev
    ```
    This will start the Vite development server, typically at `http://localhost:5173`.

## 📝 Notes

- This is a **frontend-only** project and does not require any backend.
- Bookmarks and settings are saved locally in your browser (localStorage).
- You can customize the background, fonts, and UI as per your needs.
